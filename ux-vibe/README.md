## Назначение

Файлы демонстрируют систему:

- Визуальная иллюзия живого присутствия
- Реализована через тени, градиенты, микро-анимации, текстуры
- Поддержка мобильных интерфейсов
- Интеграция с AI-Оператором
- Без изменения HTML-структуры
- Только CSS, JS-усиление

## Архитектура: 3 слоя

| Слой | Технология | Назначение |
|------|-----------|-----------|
| **1. Цвет и свет** | Градиенты, text-shadow, background-clip | Создание источника внимания |
| **2. Глубина и объём** | box-shadow, drop-shadow, скругления | Иллюзия трёхмерности |
| **3. Движение и отклик** | CSS-анимации, JS-управление, requestAnimationFrame | Реакция на действия |

## Компоненты визуального языка

### 1. Кнопки: точки отклика
- Градиентный фон: пульсирует через `animation`
- Сложная тень: внешняя + внутренняя + свечение
- При наведении: `scale(1.03)`, усиление свечения
- При клике: вспышка заливки, микро-смещение
- Анимация активации: плавное включение, не мгновенно

### 2. Баннеры: визуальные жесты
- Скругления: 20–30px
- Анимированные webp: не GIF
- Пульсирующий градиентный фон
- Микро-анимация появления: `scale` + `opacity`
- Подсветка границ: тонкая линия свечения

### 3. Навигация: точки притяжения
- Круглые иконки с градиентами
- Градиентная граница: светится как живой контур
- Тень: внешняя и внутренняя
- Активация: смена градиента, масштаб, прозрачность
- Анимация появления: плавное «выход» в поток

### 4. Заголовки: свет
- Градиентный текст: `background-clip: text`
- text-shadow: мягкая тень, как от внутреннего источника
- Анимация «печати»: текст проявляется посимвольно
- Вертикальный скан: луч при клике на «Оформить заказ»
- Свечение фона: лёгкий ореол под заголовком

### 5. Поля ввода: диалог
- Гладкий бордер с внутренним свечением
- Тени: внешняя + внутренняя
- При наведении: лёгкое увеличение
- При фокусе: всё поле оживает, цвет меняется

### 6. Микро-анимации: отклики
- Плавное появление кнопок
- Уведомления: «выплывают» из фона
- Иконки: поворот при наведении
- Текст: подсветка тенью при выборе
- Списки: поочерёдное появление

### 7. JS-усиление: когда CSS недостаточно
- Скан при оформлении: `requestAnimationFrame` + overlay
- Динамическая активация: только при `visibilityState: visible`
- Замена системных alert: через `MutationObserver`
- Адаптивность: только на мобильных
